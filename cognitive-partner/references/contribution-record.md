# 작업 안에서의 기여 기록

자동으로 매번 출력하거나 외부 저장하지 않는다. 결정이나 실험 결과가 실제로 남아야 할 때
현재 작업 메모에 최소한만 사용한다. 개인 능력 점수/진단을 만들지 않는다.

```text
작업과 결과 기준:
직접 피드백: [근거, 확인되지 않은 부분]
사용자 발화: [실제 발언 인용 또는 충실한 요약; 없으면 미관측]
사고 내용: [가설/예측/대안/증거 선택/판단 수정 중 실제로 관측한 것]
도움 조건: [사용자가 이미 말했는지, AI 설명/보기 뒤의 응답인지]
대조 근거: [자료/반례/실험 결과 또는 아직 없음]
실행 반영: [파일/설계/테스트/조사 순서에서 바뀌거나 유지된 지점]
결과: [검증된 것과 미검증, 실행 전이면 계획임을 명시]
재사용할 기준: [유용할 때 한 문장; 조건과 한계 포함]
```

## 증거 해석

- 명시적 승인: 실행 승인으로 쓸 수 있지만 이해 증거로 취급하지 않는다.
- AI 설명의 재진술: 설명을 따라온 신호일 수 있으나 독립 생성/전이 증거는 아니다.
- 사용자 가설/예측: 실제 사고 참여가 관측됐다. 정답이나 장기 향상을 뜻하지 않는다.
- 근거에 따른 수정/유지: 작업 내 검토 행동이 관측됐다. Skill이 원인이라고 단정하지 않는다.
- 다른 조건에서 적용: 그 조건에서의 적용 행동이 관측됐다. 일반 사고력 향상과 구분한다.

이 구분은 사람을 서열화하는 점수표가 아니다. 한 작업에 단계가 전부 나와야 하는 것도 아니다.
사용자 생각이 반영되지 않았다면 이유를 남긴다. 근거로 기각한 가설도 조사 범위를 좁힐 수 있다.
AI가 만든 설명이나 시뮬레이션 속 사용자 발화를 실제 사용자의 사고로 기록하지 않는다.
